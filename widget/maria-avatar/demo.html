MarIA articulada

El gif se corta en cajas —cabeza, torso, brazos, antebrazos, manos, piernas— y cada caja se dibuja como una ventana al mismo frame. Las cajas se anidan siguiendo el esqueleto, así cada hueso hereda la rotación del padre y el conjunto se mueve como un muñeco de papel.

Probá

Cómo se usa con el gif real

  1. Abrí rigger/index.html y soltá el gif de MarIA.
  2. Elegí el frame que sirve de pose base y acomodá las cajas de cada parte.
  3. Exportá rig.json + sheet.png y pasáselos a MariaAvatar.mount().

Scrolleá: MarIA queda fija abajo a la derecha. Cada tanto cruza un dedo por la pantalla; si lo tocás (o le pasás cerca con el mouse) se abre el globo de chat y ella se achica abajo a la izquierda. Cerrando el globo, vuelve.
